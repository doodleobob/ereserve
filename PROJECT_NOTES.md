# eReserve Build Notes

- Framework: PHP Laravel, MySQL database, plain CSS and JavaScript.
- Keep changes concise and avoid adding unnecessary packages or screens.
- Current reference screens: login and register auth cards.
- Resident landing page after login: blue header, white tab navigation, summary stat cards, quick actions, recent reservations panel, dark footer.
- Facilities page: filter card for search/category/availability, three-column facility/equipment cards, gradient icon image area, green available badge, blue detail button.
- Facility detail page: Back to Facilities link, detail card, reservation form, Cancel link, validated reservation submit saved as pending.
- Visual style: pale blue-green page background, centered white card, subtle shadow, navy headings, blue login action, green register action.
- Ask before changing requirements that are unclear or adding major features.
